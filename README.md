# Agents

Collection of agents I've had fun building.

Each one is self-contained and meant to be taken and adapted rather than installed. Copy the file, rewrite the config block, make it yours.

| Agent | What it does |
|---|---|
| [copy-reviewer](copy-reviewer/) | Reviews documentation prose for AI slop, factual drift, and broken mechanics, without flattening the writer's voice. Ships with the calibration log used to measure its false-positive rate. |
